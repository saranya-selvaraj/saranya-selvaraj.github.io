AI Agent Automation Pipeline

Overview

An n8n workflow where an AI agent generates a response to each incoming chat message, and the query and response are automatically logged to Google Sheets and sent by email. I built it as a hands-on prototype to demonstrate practical experience with AI-agent-driven automation — reflecting a broader interest in process and workflow automation that also shows up in my day-to-day work.

The Challenge

I wanted hands-on, practical experience building an AI-agent-driven workflow end-to-end, rather than just reading about how tools like n8n fit together. The goal was to prototype something simple but complete: an AI agent that responds to an incoming message, with that query and response automatically captured and shared — a small example of the automation thinking I already apply professionally.

Approach

I designed and built the pipeline as a hands-on prototype:

  • Set up a trigger to fire on each incoming chat message
  • Built the n8n workflow with an AI agent node to generate the response
  • Connected Google Sheets to automatically log each query and response as a new row
  • Integrated Gmail to send the query and response by email

Outcome / Impact

This is a proof-of-concept, not a measured production deployment — its purpose is to demonstrate hands-on experience with AI-agent-driven automation. That same interest in process automation shows up in my day-to-day work: I've automated document update workflows using Power Automate, cutting spec-update time from 20+ minutes to under 10 minutes per document — meaningful savings given updates typically needed to be repeated across specs for multiple products. (See the Vendor Onboarding Workflow case study for another example of that same automation thinking applied at work.)

What I Learned

Building this prototype gave me hands-on experience with how an AI agent plugs into a no-code automation tool like n8n — wiring up a trigger, an AI agent, and automatic logging and notification into one simple pipeline. Even at this small scope, it reinforced why I'm drawn to process automation as a product domain. It's the same thinking I bring to automation work at my job.
